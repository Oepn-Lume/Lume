# Assistant Operating Memory

## Milestone Logging Rule

From this point forward, every milestone implementation action in `Lume Treasury` should be written as a dedicated wiki record.

The minimum requirement for each milestone record is:

- what was implemented
- why it matters
- which files or modules changed
- what validation was run
- whether it was pushed to GitHub

## Scope

This rule applies to milestone-level engineering changes such as:

- new runtime capabilities
- training pipeline upgrades
- routing or expert-matrix upgrades
- dataset and reward-shaping expansions
- evaluation framework changes
- major documentation or wiki system additions

## Logging Location

Milestone pages should live under `wiki/milestones/`.

The wiki index and wiki log should continue to surface these milestone pages so they remain part of the repository-visible project memory.
