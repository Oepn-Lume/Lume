# Gemma Overproduces Code

## Summary
Gemma emits code and solution templates more often than the cloud, even when the live task primarily needs state continuation or concise execution guidance.

## Details
- Cloud code rate: 0.0473
- Gemma code rate: 0.2861
- This does not mean Gemma is better at coding; it means Gemma switches into generic solution mode too early.
- The cloud keeps more replies in execution-followup mode instead of template-generation mode.
